# Agency MBS Impact Analytics
Analyzing Mortgage-Backed Securities through the lens of ESG and Velocity.

## 🚀 The Mission
To reconcile internal portfolio performance against GSE (Fannie Mae) benchmarks for Social and Green impact.

## 📊 Core Functionality
* **Green Bond Attribution:** Maps CUSIPs to Energy Savings (kBTU) and Emissions (MTCO2e).
* **Social Mission Benchmarking:** Tracks portfolio share vs. Fannie Mae’s 2024 Mission Index (First-time Homebuyers, Low-Income).
* **Prepayment Velocity:** Dual-window (3mo vs 11mo) momentum modeling.

## 🛠️ Tech Stack
Python (Pandas, NumPy), Matplotlib for visualizations.
